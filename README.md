# Заказной (Zakaznoy)

Статический сайт игры «Заказной» с автоматическим определением устройства.

## Структура

- `index.html` — роутер: определяет устройство и перенаправляет на нужную версию
- `pc/index.html` — десктопная версия игры
- `mobile/index.html` — мобильная версия игры
- `404.html` — роутер для несуществующих путей

## Как работает автоопределение

При заходе на сайт `index.html` мгновенно определяет тип устройства:

- **User-Agent** — Android, iPhone, iPad, Windows Phone и др.
- **Touch/pointer** — устройства с тачскрином и coarse pointer.

Мобильные устройства → `/mobile/`, остальные → `/pc/`.

Ручной выбор версии доступен всегда:

- `?v=mobile` или `?v=pc` в URL — принудительно открыть нужную версию
- выбор запоминается в `localStorage` до очистки данных сайта
- на странице загрузки через ~2.5 сек появляются ссылки на обе версии

## Публикация

### GitHub Pages

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/` (для этого проекта: `https://barabolya7.github.io/Zakaznoy/`)

Роутер и `sw.js` учитывают префикс репозитория: `/Zakaznoy/pc/` и `/Zakaznoy/mobile/`. Редирект всегда считается от базы сайта, поэтому адрес не может превратиться в `/pc/pc/pc/...`.

### Netlify

1. Перетащите папку `zakaznoy-site` на https://app.netlify.com/drop
2. Сайт мгновенно опубликуется на бесплатном домене `*.netlify.app`

### Vercel

1. Импортируйте репозиторий на https://vercel.com/new
2. Никакой конфигурации не требуется — статика деплоится автоматически

## Офлайн-режим и установка (PWA)

Игра работает как PWA: после первого открытия её можно запускать без интернета.

- `sw.js` — сервис-воркер. Навигационные запросы (HTML) обслуживаются по схеме «сеть с таймаутом 5,5 с → кэш → офлайн-заглушка», статика (`/pc/`, `/mobile/`, иконки, манифесты) — по схеме stale-while-revalidate. Сторонние запросы (шрифты, Supabase, CDN) идут только в сеть.
- `manifest.json` (корень), `pc/manifest.json` и `mobile/manifest.json` — манифесты установки (standalone, тема `#071f10`). В них указаны иконки 32/192/512 px и отдельные maskable-версии 192/512 px.
- `icons/icon-192.png`, `icons/icon-512.png` — официальная иконка «Заказного» (Валет). `icons/icon-32.png`, `icons/apple-touch-icon.png`, `icons/favicon.ico` — фавиконки и иконка для iOS.
- `favicon.ico`, `icon-32.png`, `apple-touch-icon.png` продублированы в корне, `pc/` и `mobile/`, чтобы установка с любого адреса и «Добавить на экран Домой» на iPhone показывали новую иконку.
- Та же иконка используется как аватарка по умолчанию для гостей, офлайн-профилей и ботов без собственного фото.
- `index.html` и обе версии игры регистрируют `sw.js`. Регистрация работает только по HTTP/HTTPS (на `file://` сервис-воркер недоступен).
- Кэш версионируется константой `SW_VERSION` в `sw.js`. Имя кэша намеренно остаётся `zakaznoy-v3-jack`; browser обновляет воркер при любом изменении содержимого `sw.js`, а при установке воркер сам удаляет отравленные старые записи корневого `index.html`, сохранённые под `/pc/` или `/mobile/`.

### Поведение без сети

- Приложение не зависает на загрузке: если сеть или Supabase недоступны, меню открывается под последним сохранённым профилем (кэш на 45 дней), иначе как «Гость».
- В углу меню показывается индикатор «Офлайн-режим».
- «Мультиплеер», «Друзья», «Таблица лидеров», смена аватара и ника заблокированы и показывают пояснение: «Для игры с реальными игроками и доступа к онлайн-функциям требуется подключение к интернету».
- Игра с ботом (все сложности) и правила доступны полностью офлайн.
- При возврате в игру показывается блок «Незаконченная партия». Кнопка «Отмена» сначала переспрашивает подтверждение и показывает точный штраф; после подтверждения партия удаляется, а с ранга списываются очки по сложности бота: лёгкий — 20, средний — 40, профи — 50. В режиме обучения и у гостя очки не списываются.
- Результаты партий с ботом сразу применяются к локальному профилю (очки, победы, поражения) и ставятся в очередь `localStorage`. При появлении сети (`online`) приложение само поднимает Supabase и отправляет накопленное без перезагрузки страницы. Очередь сохраняется между запусками: при следующем онлайн-входе офлайн-дельты применяются к свежему профилю с сервера и отправляются одним обновлением. Гостевые результаты на сервер не отправляются.

### Ключи localStorage

- `zakaznoy_me_v1` — кэш профиля для офлайн-запуска.
- `zakaznoy_off_queue_v1` — очередь офлайн-результатов (очки и статистика).
- `zakaznoy_bot_game_v1` — автосохранение незаконченной партии с ботом (TTL 3 дня).
- `zakaznoj-auth` — сессия Supabase.

### Автосохранение партии

Партия с ботом сохраняется после каждого хода (руки, колода, козырь, стол, счёт, ход, сложность). После перезагрузки появляется окно «Вернуться к незаконченной партии?». При возврате показывается 15-секундное окно переподключения с обратным отсчётом и кнопкой «Продолжить сейчас»; прогресс не теряется. Сохранение удаляется при завершении партии и при явном выходе в меню.

## Примечания

- Игровая логика в `pc/index.html` и `mobile/index.html` не изменена — это копии исходных файлов `zakaznoj_v11_pc.html` и `zakaznoj_v11_mobile.html`.
- Бэкенд (Supabase) уже встроен в файлы игр и работает без дополнительной настройки.
